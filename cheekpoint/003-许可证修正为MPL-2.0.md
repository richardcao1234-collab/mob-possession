# 修改记录 003：许可证修正为 MPL-2.0

- 修改日期：2026-08-02
- 修改类型：许可证元数据与发布文档修正
- 功能代码：未修改
- 模组版本号：未修改

## 原因

项目所有者确认本项目采用 Mozilla Public License 2.0。此前 GitHub README 和所有 JAR 的 `fabric.mod.json` 错误声明为 `CC0-1.0`，需要统一修正。

## 修改内容

- GitHub README 的许可证徽章改为 `MPL-2.0`。
- GitHub README 的许可证章节改为 Mozilla Public License 2.0。
- 技术 README 增加 MPL-2.0 声明。
- 所有现有 JAR 的 `fabric.mod.json` 中 `license` 从 `CC0-1.0` 改为 `MPL-2.0`。
- 增加 Mozilla 官方 MPL 2.0 许可证正文文件 `LICENSE`。

## 发布注意事项

MPL-2.0 要求分发 Covered Software 的可执行形式时，使对应 Source Code Form 可以通过合理方式及时获得。因此 GitHub 发布不能只有 JAR；应补齐与各发布 JAR 对应、适合继续修改的完整源代码，并在 Release 页面说明源码位置。

本次只修正许可证声明，不改变任何控制、移动、网络、生物能力或兼容范围。
