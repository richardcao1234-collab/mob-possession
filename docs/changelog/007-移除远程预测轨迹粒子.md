# 修改记录 007：移除远程预测轨迹粒子

## 修改内容

- 移除附身远程生物时仅控制玩家可见的末地烛粒子预测轨迹。
- 保留附身远程生物时的原版屏幕中央准星显示。
- 保留骷髅系、烈焰人、恶魂、旋风人、末影龙、凋灵以及通用远程生物的实际攻击逻辑。
- 同步修改 README、26.2 生物列表说明和 90 种生物操作手册，避免继续描述已移除的粒子轨迹功能。

## 技术实现

- 9 个 `1.0.5` JAR 中的 `dev.mobpossession.server.TrajectoryPreviewSupport.show(...)` 均被替换为空方法。
- `PossessionCrosshairMixin` 未修改，准星显示逻辑继续保留。
