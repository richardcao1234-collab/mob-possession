## 全版本继承的修复

- 附身期间在 `serverAiStep` 开头暂停主动 AI，只影响已附身生物，不影响世界中的其他 Mob。
- 清除自主控制路径，玩家移动每 tick 只应用一次。
- 陆地默认速度为属性 × 0.35，Shift 加速为属性 × 0.70。
- 三维默认速度为 `max(0.05, 属性 × 0.5)`，Shift 再提高 35%。
- 右键和 `G` 在按住时于冷却结束后自动重试。
- 末影人只在实际方块交互成功时消耗方块能力；无效方块回退瞬移，瞬移失败 5 tick 后重试。
- 骷髅射箭不再要求先锁定活体实体。

Sulfur Cube 是 Minecraft 26.2 的新增生物，因此吸收/弹出能力仍只存在于 26.2 构建。

## 烈焰人飞行

原代码没有把 `Blaze` 纳入飞行生物判定，因此它只能沿地面移动。1.0.5 将烈焰人纳入三维移动：

- `WASD`：沿玩家视线和水平方向飞行；
- 空格：上升；
- Ctrl：下降；
- Shift：加速；
- 右键：沿玩家准星方向发射原版小火球。

## 骷髅系玩家瞄准

手动准星射箭从普通骷髅扩展到所有 `AbstractSkeleton`：

- 骷髅；
- 流浪者；
- 沼骸；
- Parched；
- 凋灵骷髅。

射箭方向直接使用玩家控制后的视线向量，散布为 0，冷却为 20 tick。箭矢仍通过各实体的原版 `getArrow` 创建，因此流浪者、沼骸等可以保留原版特殊箭数据。

## 准星与预测轨迹

- 新增客户端专用 `PossessionCrosshairMixin`，附身骑乘且相机位于目标生物时，强制显示原版屏幕中央准星。
- Mixin 位于配置的 `client` 段，专用服务器不会加载 Minecraft 客户端类。
- 新增 `TrajectoryPreviewSupport`，每 5 tick 刷新 16 个末地烛粒子预测点。
- 粒子只发送给当前控制玩家，不会向附近其他玩家广播。
- 骷髅系和通用 `RangedAttackMob` 使用带阻力与重力下坠的弹道曲线。
- 烈焰人、恶魂、旋风人、末影龙和凋灵使用近似直线轨迹。
- 预测线覆盖约 13 格，属于瞄准辅助；药水、弩箭、唾沫等通用远程弹种可能和近似曲线存在少量差异。

## 兼容实现

- 1.21.x 使用 intermediary 类名，并按 API 变化分为 1.21–1.21.2、1.21.4–1.21.8、1.21.9–1.21.11 三组辅助类。
- 26.1 和 26.2 使用官方命名空间。
- 1.21.x 新增 class 使用 `--release 21` 编译，避免 Java 25 字节码误入 Java 21 构建。

## 验证结果

- 9 个 JAR 均能被 ZIP/JAR 读取。
- 9 个 `fabric.mod.json` 版本均为 `1.0.5`，Minecraft 范围保持原值，许可证均为 `MPL-2.0`。
- 9 个 Mixin 配置均在 `client` 段注册 `PossessionCrosshairMixin`。
- 1.21.x/26.1 每个 JAR 的 15 个模组 class 通过 ASM 结构与数据流校验；26.2 的 18 个 class 通过校验。
- 反汇编确认全部版本包含 `0.35F / 0.70F / 0.05D` 速度常量、烈焰人飞行判断和轨迹调用。
- 抽查 1.21、1.21.11、26.1、26.2 的 AI 与准星 Mixin，注入目标、`HEAD` 和 `cancellable=true` 均正确。

## 建议的游戏内测试

1. 附身烈焰人，测试空格上升、Ctrl 下降、Shift 加速和 WASD 三维飞行。
2. 用烈焰人向上、向下和水平方向发射火球，确认准星、直线预测点和实际方向一致。
3. 分别附身骷髅、流浪者和沼骸，向方块或空处射箭，确认无需实体目标且箭矢沿准星飞行。
4. 附身恶魂、凋灵、旋风人以及其他通用远程生物，检查准星和预测轨迹。
5. 在多人测试服确认轨迹粒子只有控制者自己可见。
6. 测试非附身生物，确认其 AI、寻路和攻击行为完全正常。

> 当前完成的是编译、元数据、反汇编、Mixin 配置和 ASM 字节码验证；尚未代替真实 Minecraft 客户端进行游戏内视觉与手感测试。
